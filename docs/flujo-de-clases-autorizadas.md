# Flujo de clases autorizadas

## Antes de usar una fuente

1. Inicia sesión por tu cuenta en la plataforma y confirma que puedes consultar el material.
2. Selecciona la plataforma, el título, la URL oficial y una carpeta local existente.
3. Declara la autorización de grabación solo cuando la institución, el docente y las condiciones aplicables realmente la permitan.
4. Prepara el flujo. La aplicación valida HTTPS, el dominio de la plataforma y la carpeta; no descarga ni graba nada.

## Rutas por plataforma

| Plataforma | Ruta permitida en Herramientas |
| --- | --- |
| Class (UVM) y Blackboard UVM | Usar solo una descarga oficial disponible para la cuenta o una transcripción y archivos proporcionados por el curso. |
| EBAC, Mastermind, Platzi y Coursera | Usar texto seleccionado, subtítulos, exportaciones oficiales o archivos propios. No extraer vídeo protegido. |
| YouTube | Trabajar con texto, subtítulos disponibles para el usuario o material propio, respetando las condiciones aplicables. |
| Otra plataforma autorizada | El usuario confirma el dominio y utiliza únicamente material que pueda usar legítimamente. |

## Uso de OBS

OBS es un apoyo manual, no un capturador automático. Solo se puede abrir después de confirmar la autorización y el alcance de la herramienta. Una vez abierto, el usuario verifica la fuente, la carpeta y controla el inicio y fin de la grabación dentro de OBS.

## Después

1. Proporciona la transcripción VTT/SRT, el texto, el enlace público permitido o el archivo propio.
2. Revisa y edita el resumen Markdown.
3. Guarda o anexa en Obsidian únicamente si estás de acuerdo con el contenido.
4. El contexto temporal vence a los siete días; los archivos originales siguen siendo tuyos y no se eliminan.

## Criterio de aceptación del paso 4

No existe automatización de login, descarga protegida, evasión de DRM ni control automático de OBS. Cada paso sensible exige una confirmación visible y validación local.
