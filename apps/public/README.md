# Producto público pendiente

Este directorio reserva el futuro producto público. No contiene perfiles, configuraciones, claves, sesiones, contexto temporal ni archivos del modo administrador.

Antes de implementar una interfaz pública deben cumplirse las puertas de salida descritas en `../../docs/preparacion-producto-publico.md`: autenticación propia, aislamiento por cuenta, consentimiento, retención y borrado, revisión legal de proveedores y pruebas de seguridad.

El alcance inicial recomendado es texto pegado, archivos elegidos de forma explícita y enlaces públicos permitidos. Las integraciones con cursos autenticados y automatizaciones sensibles continúan desactivadas.
